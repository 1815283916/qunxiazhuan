# 配置表

以下工作簿为 `.xlsx` 格式，可使用 Excel、WPS 或 LibreOffice 编辑。每个文件包含一张同名工作表，表头已冻结并启用筛选，文本字段已设置自动换行。

| 文件 | 内容 |
| --- | --- |
| `武学.xlsx` | 武学的内力消耗、威力、范围、形状、图标、特效资源和描述 |
| `心法.xlsx` | 心法等级、攻防成长、经验需求和描述 |
| `人物属性.xlsx` | 当前六名可用人物的初始属性、模型、武学和心法等级 |
| `装备.xlsx` | 装备槽位及各项属性加成；无加成为 0 |
| `成长规则.xlsx` | 人物、武学、心法的升级与战斗经验规则 |

人物属性表中的人物编号用于配置识别。武学列表与等级列表使用 `|` 分隔，等级项格式为 `武学名称:等级`。资源列填写 `res://` 项目路径；武学特效资源指向包含连续 PNG 帧的目录，支持 `1.png` 或 `01.png` 起始编号；数值加成列均为数字。

这些工作簿用于策划维护和核对。当前游戏已同步本目录中的配置；后续修改表格后，需要再次同步更新 `scripts/game_state.gd` 中的配置定义。

武学、心法、装备和人物 ID 是稳定引用。名称调整时，应保留或更新对应 ID；删除一行会移除其运行配置，并应同时清理人物表中的相关技能引用。旧存档会迁移已知的改名装备和武学，已删除的武学引用会被清理。
