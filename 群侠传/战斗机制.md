# 战斗机制

## 设计方向

沿用现有 16×7 方格、连续时序、最多三人出战、四门武学与一门心法。武学决定这一手做什么，心法决定这个角色愿意把战斗打成什么样。战士靠交替进攻和维持阵线，神速靠行动差，反伤靠站位承压，内力流靠蓄力和资源差。四派共享同一套伤害、状态和时序规则。

本文依据《技能设计.md》提出首轮试玩规则。命中上下限、状态上限、冷却口径、连击限制和心法公式是建议值。实现时保留一套基础攻防公式，可沿用《数值与机制设计.md》的敌我统一减伤，再按实际战斗重标定。

## 时序和行动

**正常行动**允许移动一次，然后使用一门武学或调息。我方也可以用药。位移和动作确认后才提交消耗。调息占用本次动作，回复 15 点内力，我方额外回复 12 点气血。

**行动速度**影响等待时间，**移动距离**影响能走几格，两者分开。每个单位的基础行动间隔沿用现有面板。令速度倍率 S = clamp(1 + 神速加成 − 麻痹减速 − 寒冷减速, 0.55, 1.50)，实际间隔 I = max(30, ceil(基础间隔 ÷ S))。多个状态先按百分点相加，再统一限幅。

等待中的单位遇到速度变化时，保留已经走完的行动进度。剩余时间按 ceil(旧剩余时序 × 新间隔 ÷ 旧间隔) 调整，已就绪单位保持就绪。实现时可用累计进度避免同一动作里多次舍入，行动队列和预览共用结果。同一时序按稳定入场序号执行。基础间隔 90 的角色叠出三层神速时，速度 +40%，完整等待从 90 变为 65。如果原来已等完 45，状态生效后约再等 33。

**连击是受限的追加行动**。每次正常行动以武学实际造成伤害结束时，掷一次连击，成功后可追加施展一门内力充足、冷却已结束的攻击武学。追加施展正常消耗内力，不能再次移动、调息、吃药或触发连击。追加攻击不推进时序，不结算回合型回复、持续伤害、持续时间或冷却，但照常触发命中、暴击、反伤和附带状态。每次正常行动最多追加一次，时序从追加动作结束后排下一次正常行动。

**冷却统一为 2，按施展者自己的正常行动计数**。第 1 次正常行动施放，第 2 次进入冷却，第 3 次重新可用。追加行动沿用本次正常行动的序号。

## 武学范围

| 类别 | 施展范围 | 攻击范围 |
| --- | --- | --- |
| 剑系 | 点击相邻一格选择方向 | 沿该方向直线四格 |
| 刀法 | 点击相邻一格选择方向 | 前方两排，每排三格 |
| 拳掌 | 选择三格内的落点 | 仅命中落点 |
| 奇门 | 选择两格内的落点 | 以落点为中心，向四个方向各延伸两格 |

距离按横竖步数计算，攻击范围在棋盘边缘截断。武学可以空放，照常消耗内力和行动、进入冷却，并触发出招时的自身状态。空放没有命中结算和战斗经验。回春架等武学按所属类别攻击，施展时给自己加上状态。敌我共用施展、命中、内力和冷却规则，敌方自动选招时会寻找实际目标，必要时走近或调息。

## 状态结算

每个状态记录层数、剩余正常行动次数、来源和施加批次。界面将层数显示为等级，将剩余时间显示为受影响人物的回合，例如「恢复2级（2回合）」。武学说明在末尾用「（我）」或「（敌）」标记作用对象。可叠状态采用共享持续时间。再次施加时加层至上限，剩余时间取新旧较长值。不可叠状态只刷新时间。飘逸和凝神的层数同时是消耗次数，耗尽立即移除。层数变化立刻更新面板和时序。

正常行动开始时记录当前状态批次。先结算中毒，再扣寒冷内力，之后结算恢复和归元。倒地立即退出。随后检查晕眩、入魔与心法开场条件，再进入操作或 AI。动作及追加动作结束后，消耗本次开场批次的一次持续时间。行动中刚获得或刷新的状态从下次开场开始计时。这样自己施加「持续 2」的恢复，能在后续两次正常行动回复。被晕眩跳过的一次也计入持续时间和冷却。

同一正常行动连续施加同种状态时，层数按规则累计，但刷新批次只记录一次。持续状态的判定统一使用目标自己的行动数。状态效果包含明确的触发阶段，避免用动画结束或界面刷新决定是否生效。

### 建议状态口径

下表 N 表示当前层数。数值是首轮建议，主要保留你原稿中的基础强度，再给容易失控的叠层加边界。

| 状态 | 效果与上限 |
| --- | --- |
| 重伤、内伤 | 分别使所有主动与被动回血、回内减半。各 1 层，战斗入场填满资源和退回战前快照不属于回复。 |
| 连击 | 概率为 30% + 5 个百分点 × (N−1)，最多 5 层、50%。只对正常行动的有效攻击判定。 |
| 飘逸 | 闪避加 50 个百分点，最多 3 层。多层提供多次机会，闪避幅度保持 50。仅当它把原本会命中的一击变成闪避时消耗一层。 |
| 中毒 | 每次正常行动开始扣当前气血的 min(25%, 5% + 2 个百分点 × (N−1))，最多 11 层。向下取整，至少 1 点。 |
| 麻痹 | 速度降低 30% + 5 个百分点 × (N−1)，最多 5 层。 |
| 寒冷 | 速度降低 20% + 3 个百分点 × (N−1)，开场扣最大内力的 5% + 2 个百分点 × (N−1)，最多 5 层。五层为减速 32%、扣内 13%。 |
| 凝神 | 命中与暴击各加 50 个百分点，最多 3 层，强度不随层数增长。每次主动攻击消耗一层，整次范围攻击共享该层。 |
| 狂战 | 造成伤害 +30%、受到直接伤害 +20%，1 层。 |
| 神速 | 速度提高 30% + 5 个百分点 × (N−1)，最多 5 层。 |
| 定身 | 无法主动移动，可以出招、用药和调息，1 层。 |
| 晕眩 | 跳过一次正常行动，1 层。结束后获得晕眩免疫，直到下一次未被跳过的正常行动结束。 |
| 致盲 | 1 层。按流派缩小瞄准和覆盖范围，实际可攻击格取原形状与受限形状的交集。剑系限直线两格、拳掌限相邻目标、刀法限前方一排三格、奇门限相邻落点及其十字五格。 |
| 攻击提高／攻击弱化 | 各自按 ±(20% + 5 个百分点 × (N−1))，各最多 5 层。同一属性的加减先相加。 |
| 防御提高／防御弱化 | 规则同上。原稿第 17 条的名称应为「防御弱化」。 |
| 天人合一 | 获得时清除现有负面状态，并在持续期间免疫新负面，受到直接伤害减半，1 层。 |
| 归元、恢复 | 每次正常行动开始分别回复最大内力、最大气血的 5% × N，各最多 3 层。重伤和内伤在最终回复前生效。 |
| 入魔 | 行动改由 AI 接管，允许攻击友军，命中时必暴击，暴伤倍率额外加 0.30，1 层。首轮限定持续 1 次正常行动。 |
| 坚守 | 攻击 −30%、防御 +50%，1 层。与同属性其他修正相加。 |

正负状态靠效果标签区分，状态名不承担判断职责。负面免疫只挡新施加，清除现有状态由效果单独声明。调息和药品的回复也走同一入口，统一处理重伤、内伤、取整和上限。

## 攻击和心法触发顺序

1. 检查目标、形状、冷却和内力，锁定本次受影响单位，扣技能消耗。攻击出手时取凝神等攻击快照，结算该次层数消耗。范围预览与实际结算用同一套形状，逐目标判命中。
2. 命中率建议为 clamp(90% + 命中加成 − 闪避加成, 10%, 100%)。逐目标判暴击，普通暴击率上限建议 85%。入魔的必暴击仍须先命中，晕眩优先于入魔。普通暴击倍率先用 1.5。
3. 敌我用同一基础伤害。建议先由攻击、威力、熟练和武学等级算出招式伤害。主伤乘暴击倍率，然后加上按非暴击招式伤害算出的内力附伤，两部分一起乘 100 ÷ (100 + 目标有效防御) 与范围系数。攻击／防御百分比先折算到面板，狂战等直接伤害修正随后生效。同类修正相加，多个直接减伤来源相乘，常规直接减伤合计封顶 75%。计算中间值保留精度，进入内力抵挡前向下取整。
4. 结算内力抵挡和实际气血损失，记录本击是否使目标倒地。命中附带状态施加给仍存活的目标，自身增益按技能标记在出手时或命中后生效。再处理反伤。反伤、毒伤和内力扣除各用独立事件类别，反伤与毒伤不能触发反伤、连击或普通命中效果。所有本次攻击事件处理完再判胜负。双方同时全灭时按失败处理，玩家收到明确说明。
5. 敌我 AI、手动操作和预览共用同一套可行动作与结算。预览显示命中率、非暴击预期气血损失、内力抵挡、预计反伤和附带状态。存在随机结果时分开标明。

## 四个流派怎样打起来

**战士流适合守住位置并交替用招。** 回春架在攻击时给施展者恢复状态，断脉掌给命中的敌人施加重伤。震岳拳施展时提升自身攻防，命中后施加晕眩。对手可用重伤压回血，或拖到攻防增益结束再进攻。

**神速流要选择接敌和避战的节奏。** 神速一层可以来自准备动作。神速三层与连击三层建议放在一门轻击武学上，出手时获得神速，命中后获得连击，才会在这一次正常行动结束时按 40% 判追加。心法记录从上次正常行动及其追加动作结束到本次开场心法判定前是否有任何气血损失，本次开场毒伤也计入，战斗首动不触发。无伤时，本次行动得到三层攻击提高和一层凝神，这两项在本次正常行动及其追加机会结束时过期。原稿中的「缓速」可作为麻痹、寒冷等速度下降效果的标签，建议让心法免疫减速、定身，寒冷的扣内部分仍然生效。对手可用远程轻击打断无伤条件，或用致盲破坏出招距离。

**反伤流的价值来自替队伍占住要害。** 心法使移动距离 −1，最低 1，受到直接伤害 −30%。按技能原稿，反伤基数取本心法减伤前的伤害，已经计入防御和其他直接伤害修正。敌人打出 100 点经防御折算的伤害，心法减至 70，反伤 50。该反伤直接扣气血，可致倒地，守方被这一击击倒仍结算。持续伤害、友军伤害和其他反伤不触发。关卡要有能争夺的窄口或目标，否则敌人理性绕开坦克时，反伤心法缺少发挥场景。

**内力流需要在进攻和防御之间花同一份内力。** 建议以支付出招成本后的内力计算差额，差额比例 = max(0, 我方当前内力 − 对方当前内力) ÷ max(1, 双方最大内力中的较大值)。主动命中时附加最多 25% 的非暴击招式伤害，比例取 min(25%, 差额比例 × 50%)。附伤不享受额外暴击倍率，随本击一起接受目标减伤和内力抵挡。守方抵挡量为 min(当前内力, floor(本击待扣气血 × 60%))，每挡 1 点消耗 1 内力。如果待扣气血为 50、只剩 20 内力，就花光 20 内力并扣 30 气血。高等级寒冷是这个流派的强压制手段，可通过内力成本和状态持续回合控制覆盖率。对手可以先用低消耗招式耗空护盾，再用高伤害武学收尾。

## 首轮试玩与落地顺序

先验证时序、冷却、攻击事件与状态的结算，再检查反伤和内力抵挡。每门武学独立填写基础威力、消耗内力、威力成长和状态效果，范围与冷却取通用模板。每条效果标明对象、触发阶段、等级及持续回合。心法配置以事件触发器和条件为主。

酒家用来验证移动、武学冷却和调息的衔接。雪山刺客用连击和寒冷检验玩家能否看懂威胁并集火或避开。天龙寺用六个行动错开的敌人检查速度上限与控制抗锁，并分别试一次无伤神速、反伤守路和低内力破盾。比较相同装备和等级下的主动攻击次数、累计伤害、净承伤、消耗内力及失败原因。

首轮特别检查三层神速与三层连击同时存在时，基础间隔 90 变为 65，符合触发条件的行动平均约 1.4 次攻击机会，两者在理想情况下合计接近无增益时的 1.94 倍。这个上界说明神速武学不宜再给与战士同档的单击威力。再验证一轮晕眩后目标有机会出手、双方反伤不会循环、追加攻击不会让冷却和回内多跳一次，以及致盲的绿色可用格与实际命中一致。
